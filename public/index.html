      How it works: both devices join the same 6-digit room via WebSocket. The sender's browser then connects directly to the receiver with WebRTC (STUN-assisted). File bytes travel peer-to-peer in 16 KB chunks and never touch disk on any server. If both devices are behind strict NATs where direct UDP fails, the app falls back to relaying chunks through the signaling server — slower, but it works. For guaranteed direct transfers across any network in production, add a TURN server (see README).
